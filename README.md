This repository contains:

1. **AC Dashboard**: An online monitoring dashboard designed to visualise and track the key operational, chemical, and environmental parameters required for the successful implementation and monitoring of a Wastewater Alkalinity Enhancement (WAE) project.

2. **Geochemical Model**: A geochemical modelling framework developed to estimate mineral dissolution kinetics, carbonate system behaviour, and the steady-state mass addition requirements needed to achieve carbon dioxide removal in wastewater systems.

3. **Sensor Data Collection Framework**: Documentation and integration details for low-cost inline sensor systems capable of continuously monitoring wastewater chemistry in real time. These measurements are essential for understanding baseline conditions, tracking process dynamics, and evaluating chemical changes before and after alkalinity enhancement interventions.

4. **Treatment Performance Summary Report**: A detailed summary of pilot-scale WAE treatment performance conducted in collaboration with the Institute of Chemical Technology. The report includes experimental observations, water quality analysis, operational insights, and preliminary findings related to alkalinity enhancement, carbon removal potential, and system performance under real wastewater conditions.
